# Kodza requests

Ask for a component. Vote for the ones you want. The most wanted ships first.

There is no code here. Kodza's components live on [kodza.dev](https://kodza.dev): free, plain
HTML, CSS and JS, zero dependencies, and your AI can fetch them.

## Request a component

1. **Search [Requests](https://github.com/kodza-dev/requests/discussions/categories/requests) first.**
   Someone may have asked already. Upvote it instead of asking twice.
2. **Nothing there? [Open a request](https://github.com/kodza-dev/requests/discussions/new?category=requests).**
   Say what it does, and where you would use it on a real site.
3. **Upvote** with the arrow next to a request. Once a week, the most voted one becomes the
   component of the day: "Shipped: your request."

When your request ships, its page on kodza.dev says *Requested by @you*. Forever.

## Found a bug?

[Open an issue](https://github.com/kodza-dev/requests/issues/new/choose) with the component,
what you did and what broke. Your browser and a screenshot help a lot.

## What won't ship

- **A wrapper around a library.** No GSAP, no Three.js, no jQuery. Kodza has zero dependencies,
  and that's the point.
- **An effect nobody uses outside a demo.** Every component needs a real place on a real page.
- **A color variant of something that already exists.** Use its CSS variables.

## Fine print

A request is an idea, not a contribution: Kodza designs, builds and maintains every component.
Using Kodza is free, in any project. Reselling it isn't. The license is on the site.
